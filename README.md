# 华服志 · 汉服与非遗文化展示网站

欢迎来到“华服志”！这是一个基于原生前端技术（HTML/CSS/JS）开发的汉服与非物质文化遗产科普展示网站，专为 AI 网站创作赛道设计。

## 🔗 在线预览
👉 **[点击这里访问《华服志》在线网站](https://uuuiq-m.github.io/huafuzhi-web/)**

## ✨ 核心功能 (v3.0 版本)
- **🎨 传统色交互工具**：提供 12 种中国传统色卡，点击可查看文化出处，支持“一键复制色值”与“智能生成 5 色 UI 配色方案”。
- **🏮 沉浸式文化科普**：包含衣冠简史（时间轴）、形制图鉴、华服配件、华夏礼仪、传统纹样、非遗织造（点击卡片查看弹窗）等 6 大图文板块。
- **🌸 趣味交互特效**：网页全屏支持“鼠标点击飘落花瓣”特效。
- **🎵 视听体验**：右下角悬浮古风背景音乐播放器，支持一键播放/暂停。
- **📝 趣味小考**：内置 7 道汉服知识互动问答题，实时计分。
- **📱 响应式设计**：完美适配电脑端与手机端浏览。

## 🛠️ 技术栈
- **HTML5**：语义化标签构建页面结构。
- **CSS3**：Flexbox / Grid 响应式布局、CSS 变量、关键帧动画（渐显、花瓣飘落、图标旋转）。
- **JavaScript (ES6)**：DOM 操作、IntersectionObserver（滚动动画）、Clipboard API（剪贴板复制）、原生 Audio API、算法生成色彩方案。
- **部署**：GitHub Pages 自动化托管。

## 📦 版本迭代记录
- **v1.0**：基础框架搭建，完成轮播、选项卡与基本排版。
- **v2.0**：新增华服诗词板块，加入点击落花特效，扩充 12 种传统色与 7 道问答题。
- **v3.0**：全面升级色卡交互（复制与配色算法），深度扩充非遗、礼仪、配件与纹样等图文内容。
